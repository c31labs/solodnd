# Contributions and feedback

Lanternbound is a proprietary C31 Labs project. It is not accepting public source code contributions under an open source model.

## Welcome participation

You are welcome to:

1. Report a reproducible bug that does not expose private information.
2. Suggest an accessibility improvement.
3. Share feedback about the solo play experience.
4. Suggest a future world, chapter, character option, or safety improvement.
5. Report a vulnerability privately under `SECURITY.md`.

## Code submissions

Do not submit code, artwork, fiction, translations, or other copyright material unless C31 Labs has first invited the contribution and both parties have completed an appropriate written contributor agreement.

Opening a pull request does not grant permission to copy, modify, deploy, or distribute Lanternbound. Unsolicited pull requests may be closed without review to avoid ownership and licensing uncertainty.

## Public reports

Public issues must not contain passwords, API keys, account tokens, private journal content, personal information, exploit instructions, or another player’s data.

Use the Direwrought contact route at `https://direwrought.com/` when information should remain private.
